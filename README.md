# HTTP Security Headers & SSL/TLS Checker

A Python CLI tool that audits a website's SSL/TLS certificate details and checks key HTTP security headers (`Strict-Transport-Security`, `Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, and `Permissions-Policy`), providing a security score, grade, and remediation guidance.

## Usage

pip install -r requirements.txt
python3 checker.py
